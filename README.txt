Minecraft 1.21.11 / Fabric / Java 21 - КЛИЕНТСКИЙ мод, работает на любом сервере

ЧТО ДЕЛАЕТ:
 Раз в секунду проверяет игроков, которых вы видите в игре (в пределах
 обычной дальности отрисовки). Если кто-то не из списка друзей оказался
 ближе радиуса до отмеченной базы - показывает сообщение в чате (видно
 только вам), играет звук и отправляет @everyone в ваш Discord-канал
 через вебхук.

ОГРАНИЧЕНИЕ: видит только тех игроков, которых вам и так показывает игра
(обычно 100-200+ блоков, зависит от настроек сервера). Совсем издалека
не заметит.

КОМАНДЫ (пишутся прямо в игре, с точкой вместо слэша тоже работает):
 /basealarm setbase          - отметить базу там, где вы сейчас стоите
 /basealarm radius <число>   - радиус срабатывания (по умолчанию 50)
 /basealarm webhook <ссылка> - вставить ссылку вашего вебхука Discord
 /basealarm friend add <имя> - добавить друга (тревога на него не сработает)
 /basealarm friend remove <имя>
 /basealarm friend list
 /basealarm status           - показать текущие настройки

КАК СДЕЛАТЬ ВЕБХУК В DISCORD:
 Настройки канала -> Интеграции -> Вебхуки -> Создать вебхук -> Копировать URL.
 Затем в игре: /basealarm webhook <вставить скопированную ссылку>

СБОРКА: через GitHub Actions (как с предыдущими модами) или ./gradlew build.
Готовый jar: build/libs/basealarm-1.0.0.jar -> в папку mods.

НАСТРОЙКИ хранятся в файле .minecraft/config/basealarm.json и не теряются
между запусками игры.
